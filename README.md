For this assignment, I used Python to solve three cryptography problems involving RSA, ElGamal, and ECC. Each program performs the calculations and checks the results.

Files

RSA.py – Finds the private key and encrypts "HOW ARE YOU".

ElGamal.py – Generates keys, encrypts "HELLO", and decrypts it.

ECC.py – Uses point addition and multiplication to encrypt and decrypt a point.

How to Run

Open the terminal in VS Code and run:

python RSA.py
python ElGamal.py
python ECC.py

All programs use Python 3 and do not require additional libraries.
